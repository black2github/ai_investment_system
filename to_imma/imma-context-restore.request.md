## 2. Как устроен обмен
- Заказы и приёмки приходят одним сообщением между «=== НАЧАЛО ===» и «=== КОНЕЦ ===», вложения — файлы из workspace.
- Твой ответ — YAML/MD-файлы в пакете (скачиваемый архив или отдельные файлы) + PACKAGE_MANIFEST.yaml с sha256 +
  короткий текст в чате. Каждый файл несёт версию в имени и внутри.
- **Переиздание = полный текст предыдущей версии + дельта**, дельта отдельно в patch notes (ты записала это правило
  сама в Dozor v1.2.1; на нашей стороне полнота замены проверяется инструментом сравнения деревьев YAML — пропажа
  раздела без явного обоснования = отказ приёмки).
- Приёмка на нашей стороне механическая: JSON Schema Draft 2020-12, правила целостности валидатора, живые прогоны
  движка; «локально проходит схему» — не приёмка, приёмка — host-run.
- Все числа — с провенансом: verified_fact (URL + дата документа) | derived_fact (формула) | model_assumption
  (rationale) | owner_judgment (только при решении владельца); прогнозы компаний — company_guidance, не actual;
  период факта сохраняется дословно; нераскрытое не оценивается.
